# Usage Notes for LLMs

When starting a Solidus session:
1. Load this spec (~2K tokens)
2. Select profile matching task (geometry, extraction, conversion, chi_integration)
3. Load files from that profile's include list
4. Check [format_contracts] for invariants that must hold

When modifying Solidus:
- Keep Rust crates in subdirs (cargo compatibility)
- Update this spec when adding significant functions
- Add [fn ...] entries for key algorithms
- Maintain traceability chain (every output knows its source)

Key insight: Solidus preserves curves as curves. Tessellation is deferred to the consumer (Chi). This enables resolution-independent rendering and future GPU curve evaluation.
